# 师大·日常
### 校园很大，日常不必绕。

师大·日常是一款面向江西师范大学学生的非官方校园日常工具网页，整合课表、待办、专注计时、校园服务与学习资料。

我们希望，查看今天的课程、记下要做的事、开始一段专注，以及寻找常用入口，不必总在多个页面之间来回切换。让熟悉的工具，在同一处接上日常。

## 为什么做师大·日常

校园里并不缺工具，但信息常常散落在不同的地方：课程安排在课表里，作业记在聊天记录中，学习资料存成了零散链接，办事时又要重新寻找入口。

这个项目从一次课程作业出发，尝试围绕真实的校园使用场景，把这些细小却高频的需求整理到一起。我们不希望只做一个展示功能的页面，更希望它能够成为同学愿意再次打开的日常工具。

## 一天的事，在一处接上

### 课表：一周全貌，点开细节
以周视图查看课程安排，支持切换周次，并按课程设置区分单双周。先看清一周，再点开课程了解时间、地点等具体信息，让“接下来上什么课”更容易找到。

### 待办：先记下来，再慢慢完成
记录学习与生活任务，按分类和状态整理。待办不仅是一份清单，也可以成为开始专注的入口，让“准备做什么”和“正在做什么”接在一起。

### 专注：先选节奏，再开始
提供四种专注／短休息预设：硬核 50／10、心流 90／20、经典 25／5、起步 15／3，时间单位均为分钟，便于按任务和精力选择节奏。

本地版本已支持待办与专注关联，并记录相关投入。计时结束不自动代表任务完成：投入记下来，完成自己定。

### 校园服务：办事，先找到入口
把常用校园服务按场景整理，减少重复查找网址。地图探索目前聚焦瑶湖校区的惟义楼与实验大楼，可从服务入口或课程详情进入，在配置好服务的环境下查询建筑间步行路线，并返回原课程。

### 学习资料：让信息有处可找
将学习相关信息分为关于推免、转专业、关于比赛、考试与荣誉、学习支持五类，提供分类、搜索和来源查看，也保留个人常用链接的整理入口。

资料目录帮助寻找信息，不替代学校与学院当届正式通知；历史实例和往年赛程不作为当前截止时间或资格认定依据。

## 校园气质，不只一张背景

我们希望工具有自己的校园气息，而不只是把校名放在标题上。

以校园建筑与湖面意象、水彩淡彩、浅色纸张和书页 JXNU 标识形成视觉线索，让界面随一天中的六个时段变化。白天与夜晚有不同的光影，也尽量保留日常阅读的清楚与轻松。

让暮春与早夏，在这一方电子日常里相逢。

## 当前进展

项目已完成课堂展示，核心功能已有本地实现，仍处于持续完善的早期阶段。本仓库目前先建立项目介绍，源码、运行方法及脱敏后的界面预览将在整理检查后补充。

后续优先做好版本一致性、数据保存与恢复、不同设备上的使用体验，以及少量真实用户的持续试用，而不是一味增加栏目。

## 使用与运行说明

当前产品形态是网页应用。地图等联网功能需要网络与相应服务配置，不代表下载文件后即可直接使用全部功能。

个人课表、待办等记录与源码是不同的内容，不能靠上传仓库自动备份。公开示例不应包含真实个人数据，具体运行与备份方法将在后续说明中补充。
