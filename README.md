# 师大·日常

### 校园很大，日常不必绕。

师大·日常是一款面向江西师范大学学生的非官方校园日常工具网页，整合课表、待办、专注计时、校园服务与学习资料。

我们希望，查看今天的课程、记下要做的事、开始一段专注，以及寻找常用入口，不必总在多个页面之间来回切换。让熟悉的工具，在同一处接上日常。

> 早期 Alpha · 本地优先 · 非官方学生作品。本源码版默认空白数据，云同步停用；地图需有效运行环境与网络。

## 为什么做师大·日常

校园里并不缺工具，但信息常常散落在不同的地方：课程安排在课表里，作业记在聊天记录中，学习资料存成零散链接，电费、洗衣、饮水等服务又分散在不同入口，让人“乱花渐欲乱人眼”。

这个项目从一次课程作业出发，尝试围绕真实的校园使用场景，把这些细小却高频的需求整理到一起。我们不希望只做一个展示功能的页面，更希望它能够成为同学愿意再次打开的日常工具。

## 一天的事，在一处接上

### 课表：一周全貌，点开细节

以周视图查看课程安排，支持切换周次、起止周和单双周。先看清一周，再点开课程了解时间与地点。可手动添加课程，也可在本机解析已保存的教务 HTML 或导入 CSV，预览核对后追加；不代登录、不读取学校密码、不自动同步。

支持日期整体停课、参考日补课与单课停调补规则；规则需自行确认，不自动将历史校历当作当前排课事实。手机端保留整周总览与清晰阅读方式，也提供课表图片及 ICS 导出。

### 待办：先记下来，再慢慢完成

记录截止待办或同日时段安排，按分类与状态整理。待办可以成为开始专注的入口，让“准备做什么”和“正在做什么”接在一起。提醒只在页面打开且获得浏览器权限时检查，不是关闭页面后的推送。

### 专注：先选节奏，再开始

提供四种专注／短休息预设：**硬核 50／10、心流 90／20、经典 25／5、起步 15／3**，单位均为分钟；预设不是四种不同计时器。

已支持待办关联、实际投入记录和逐条完成确认。计时结束不自动代表任务完成：投入记下来，完成自己定。

### 校园服务：办事，先找到入口

常用校园服务按场景整理，减少重复找网址；教务、图书馆等官方入口在原站办理。

地图聚焦瑶湖校区惟义楼与实验大楼，并保留另外三处公开 POI。可从服务或课程详情进入，同一个腾讯地图实例承载选楼、方向球和步行路线，再返回课程。**没有有效代理时只保留地点列表，不伪造底图或路线**；不提供楼层、入口或室内教室定位。

### 学习资料：让信息有处可找

将学习信息分为关于推免、转专业、关于比赛、考试与荣誉、学习支持五类，支持分类、搜索、来源查看和个人常用链接整理。

目录帮助寻找信息，不替代学校与学院当届正式通知；历史实例、往年赛程不是当前截止时间或资格认定依据。

## 校园气质，不只一张背景

我们希望工具有自己的校园气息，而不只是把校名放在标题上。

以校园建筑与湖面意象、水彩淡彩、浅色纸张和完整书页 JXNU 标识形成视觉线索。界面随一天中的六个时段变化，夜晚仍有浅蓝、浅紫纸面；手动体验光影，不改变课程与待办的真实日期。

让暮春与早夏，在这一方电子日常里相逢。

## 当前进展与源码版范围

项目已完成课堂展示，核心工具已有实现，仍处于持续完善的早期阶段。这份目录是**独立整理的公开空白源码副本**，不包含个人课表、待办、宿舍身份、电费截图、成员材料或浏览器档案，也不代表原本地应用与线上版已同步。

- 保留较新的课表日期规则、待办—专注关联与校园视觉。
- `data.js` 从零构造；课程、待办、占用与电费快照为空。示例学期、作息需要自行设置。
- 生活圈只读虚构示例和天气固定演示值有明确标记，不是共享业务后台。
- 电费默认个人空白模式；“演示预览”仅在内存展示虚构余额，不保存为个人数据。
- 实验云同步默认停用、配置为占位，且不加载云 SDK。恢复可靠性与权限尚未验收，不能只填配置就启用。
- 本地存储键与原项目不同；新副本不会自动读取原应用的数据。
- 暂未附带原展示截图、课堂文件或未逐张核验的简介页面；上传源码不等于发布网站。

后续优先改善版本一致性、保存与恢复、不同设备上的使用体验和小范围持续试用，而不是一味增加栏目。学校业务接入仍需独立授权与认证，不把站外入口说成已接通接口。

## 本地运行

### 推荐：使用已有 Node.js 20 或更新版本

在本目录打开终端，运行：

```sh
node server.cjs
```

浏览器访问 **<http://127.0.0.1:8094\*\*。本项目使用原生> HTML／CSS／JavaScript 和 Node 内置模块，**&#x4E0D;需要 `npm install`，没有编译步骤\*\*。服务默认只监听本机。

如果系统没有 Node.js，文件双击 `index.html` 可作本地工具兼容方式，但 `file://` 存储来源因浏览器而异，不提供 Node 地图代理或动态源码下载，建议后续用 HTTP 方式运行。不要为了首次预览把个人存档复制进本目录。

首次使用：

1. 在“我的”或课表中设置实际第一教学周的星期一。
2. 手动添加或在本机导入课程，核对时间、地点与周次。
3. 通过“数据管理”导出 JSON，另存个人位置；不要提交到公开仓库。

### 可选地图服务

默认不提供 key，不调用原作者服务。WorkBuddy 安全文件预览可在其运行环境提供安全代理；普通自建 HTTP 服务不是同一个环境。

自托管代理仅读取服务端环境变量：

| 变量                     | 用途                                    |
| ---------------------- | ------------------------------------- |
| `TENCENT_MAP_KEY`      | 服务端地图 key，不写进前端、命令示例或仓库               |
| `TENCENT_MAP_SK`       | 服务端签名凭据，禁止公开                          |
| `CAMPUS_PUBLIC_ORIGIN` | 公开运行时的准确 HTTP(S) 源，例如最终 HTTPS 域名，不带路径 |
| `PORT` / `HOST`        | 监听配置，默认 8094 / 127.0.0.1              |

服务不自动加载 `.env`。此目录未配置真实地图、未做本次真实路线验收；GitHub Pages 等纯静态托管无法运行此 Node 代理。代理仅限瑶湖区域，内存限流不等于跨实例配额控制。公开部署前还需核对上游条款、域名限制、额度及服务端权限。
